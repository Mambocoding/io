## 0.2.277

owes: none — CLAUDE.md declares the two agent workflows as a deliberate divergence and their tool names as a no-brands carve-out (the human, 2026-10-19); nothing to do.
owes: none — an instrument added on the hub (*add by search*, *add by symbol*, the portfolio import) now always carries an `assetClass`, derived from its chart symbol and kind, so the phone's `WatchlistMapper` reads it instead of dropping it (SPEC-096, ALN-89); the four `stocks.*` collections are encoded and decoded through DataCore's codecs. No migration, key or default changes. An instrument added on the hub before this release has no class and stays missing on the phone until it is categorised or reordered on the hub, which writes one; removing and adding it again does the same.
owes: a changed default (SPEC-096, ALN-90) — the hub now fetches an instrument's `CSV` and `COIN` links (an `EU_ETF`'s or `COMMODITY`'s second link, a `CRYPTO`'s first) instead of recording them `role_unsupported`. An operator who set `address_csv` or `address_coin` in `stocks.settings` now sees the hub make a request to that address, one per symbol per round, through the egress guard and the per-origin budget; one who wants none clears the address. The requests are `/q/l/?s=<symbol>&f=sd2t2ohlcv&h&e=csv` and `/simple/price?ids=<id>&vs_currencies=usd&include_24hr_change=true&include_last_updated_at=true` on that address, so an endpoint of another shape answers `unparseable` or an HTTP status on its health row. No migration, key or wire change.
