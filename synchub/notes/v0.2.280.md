owes: a collection on the wire, meaning unchanged (DataCore SPEC-020, SPEC-189 §1) — every `feed.*` record is read and written by DataCore's codecs: the hub now writes `/` as `\/` and the phone's field order, and an edit is decode, copy, encode, so `feed.subscriptions`' ninth key `fetchViaBrowser` (absent reads as false, never set by the hub) and any key a newer phone adds go back unchanged. owes: a collection on the wire, meaning unchanged (DataCore SPEC-020, SPEC-122) — every `weather.*` record is read and written by DataCore's codecs, the sensor key and accuracy id by its `WeatherRecordIds`, with identical bytes for the shared forecasts and accuracy figures the hub writes (so no revision moves on the update). A forecast day missing its date or a temperature drops alone instead of the whole record. No migration, no configuration key.
